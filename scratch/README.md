# Scratch Work

Photos and handwritten notes from phone go here.

## How to upload from your phone

1. Open this repo on GitHub in your phone browser: https://github.com/D1gits0/zero-to-qml
2. Navigate to the `scratch/` folder (or the relevant week subfolder)
3. Tap **Add file → Upload files**
4. Select photos from your camera roll
5. Write a short commit message (e.g. "week1 gate math notes") and commit

## Organization

```
scratch/
├── week1-2/       # Tensor products, basic gate math
├── week3-4/       # Circuit diagrams, CNOT derivations
└── misc/          # Anything that doesn't fit yet
```

Name files descriptively when you can: `hadamard_derivation.jpg`, `cnot_truth_table.png`, etc.
